## Get old districts by city code
```sh
url = "https://api.batdongsan.com.vn/bff-seller/locations/old-districts?city={city_code}"
```

## Get streets by old district_id
```sh
url = "https://api.batdongsan.com.vn/bff-seller/locations/old-districts/{district_id}/streets"
```

## Get wards by old district_id
```sh
url = "https://api.batdongsan.com.vn/bff-seller/locations/old-districts/{district_id}/old-wards"
```

## Get new ward by city code
```sh
url = "https://api.batdongsan.com.vn/bff-seller/locations/cities/{city_code}/wards"
```

## Get new street by ward_id
```sh
url = "https://api.batdongsan.com.vn/bff-seller/locations/wards/{ward_id}/streets"
```
